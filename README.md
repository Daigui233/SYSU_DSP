# SYSU 数字信号处理课程作业

## For Human

完成课程基础与进阶任务，具体要求见 [课程要求](reference/大作业%20要求%20261112.pdf)。

- **基础模块**：自主实现 MATLAB 32/128 点 FFT、IFFT、快速卷积、重叠相加与重叠保留。
- **CMA**：实现频域 CMA 均衡与 4QAM 解调，对比星座图、EVM 及不同抽头长度的效果。
- **Verilog**：实现 32/64 点全并行 FFT，完成 Vivado 仿真、实现及资源与时序分析。

仅使用以下四个分支，三个开发分支各对应一个模块文件夹，`main` 汇总全部模块。

| 分支 | 对应目录 | 用途 |
| --- | --- | --- |
| `main` | 仓库根目录，集成全部模块 | 保存稳定 baseline |
| `basic` | `basic/` | FFT 与卷积基础模块 |
| `cma` | `cma/` | CMA 均衡与效果分析 |
| `verilog` | `verilog/` | 硬件 FFT 与验证 |

开发原则：阶段内可用进展提交到对应分支；验证通过并经人工审查后合并到 `main`，形成一轮 baseline。先完成基础模块，再推进 CMA 与 Verilog；代码可读、结果可复现。

## For Agent

- 开始前阅读课程要求与现有代码，在对应开发分支和目录内工作；复用已完成模块，避免重复实现。
- 保持代码简洁、命名清晰；注明输入输出、维度或位宽，解释关键公式、索引和数值处理，便于人工审查。
- MATLAB 禁用内置 `fft/ifft` 等相关变换函数，手动实现旋转因子及其优化。
- Verilog 禁用 FFT IP；实部、虚部输入输出各 8 bit；乘法使用延迟为 3 周期的 IP 或原语，不用 `*`。目标器件为 `xcvu13p-flga2577-2-i`，时钟 250 MHz。
- 代码与测试分开；提交前运行相关测试，简要记录运行方法、结果和已知问题，不将未验证内容描述为已完成。
- **任何提交版本均不得包含临时文件、缓存、调试日志或中间产物**；提交前检查文件清单并维护 `.gitignore`。测试结果仅保留必要的最终数据、图表及复现参数。
- 保留 `reference/` 原始资料；硬件工程保留重建所需的脚本、约束及 IP 配置。

三个模块统一采用以下结构，按需创建：

```text
basic/、cma/、verilog/
├── src/       代码及必要配置
├── tests/     测试代码与必要测试输入
└── results/   最终测试数据、图表及复现说明
```
