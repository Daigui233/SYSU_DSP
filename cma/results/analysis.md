# CMA 抽头长度对照实验

## 本轮设计与复现

在仓库根目录运行 `addpath('cma/src'); run_cma;`，默认比较 5/9/17/33 抽头。也可显式运行 `run_cma([5, 9, 17, 33])`。MATLAB R2025a，教师输入为 `TD_TRdata.mat` 的 RTdataX、RTdataY。

选择过程为：先以教师的 33 抽头验证实现；初轮增加至 65 后未获改善，因此本轮从 33 向 17、9、5 缩短，检查较短均衡器是否退化。各配置独立从中心直接通路抽头为 1、交叉通路为 0 开始，不继承其他配置训练后的抽头。

| 控制变量 | 四组共同设置 |
| --- | --- |
| 输入与次序 | 同一份数据，每路 639616 点，顺序处理一遍 |
| 分块及更新 | 每块 32 点，每 4 块更新一次，共 4997 次 |
| 步长、目标模平方、延迟 | 2^-8、Rx=Ry=2、clk_dly=1 |
| FFT 长度 | 全部为 64 点 |
| 统计区间 | 末尾 131072 点 |
| 算法 | 原参考 CMA；仅将滤波换成 basic 的频域分块实现 |

没有增加相位/频偏恢复，也没有改变恒模梯度。现有评价中的功率归一化与常相位对齐仅计算判决辅助 EVM，不反馈到 CMA。由于没有发送参考符号且输出仍旋转，本轮主要比较原输出的恒模代价 J=mean((2−|y|²)²)，不以细小 EVM 差异判断抽头优劣。

## 验证

四组均通过固定核四块滤波、167 点短序列、4096 点自适应序列及全量教师参考对照，共 16 项；另通过理想旋转缩放 QPSK 与加噪 QPSK 的评价测试。短序列覆盖完整更新、下一组新抽头使用、不足 32 点截断和不足四块不更新。

参考对照执行教师原始计算段，仅替换 tap_len。归一化差异定义为 max(abs(actual−reference))/max(1,max(abs(reference)))，全量容差 1e-9。

| 抽头数 | 全量输出差异 | 恒模误差序列差异 | 全部抽头历史差异 |
| --- | ---: | ---: | ---: |
| 5 | 1.29e-15 | 1.89e-15 | 1.15e-15 |
| 9 | 8.57e-16 | 1.80e-15 | 5.19e-16 |
| 17 | 9.15e-16 | 1.91e-15 | 4.66e-16 |
| 33 | 1.10e-15 | 2.14e-15 | 6.07e-16 |

记录见 [validation.csv](validation.csv)。样本数与更新次数还在实验入口作一致性核对，最终表中单独记录 update_count。

## 本轮结果与结论

| 抽头数 | 恒模代价 X | 恒模代价 Y | 两路平均 | 相对 17 抽头 | EVM X/Y (%) |
| --- | ---: | ---: | ---: | ---: | ---: |
| 5 | 0.21684 | 0.20330 | 0.21007 | +43.89% | 46.00 / 45.94 |
| 9 | 0.16558 | 0.16686 | 0.16622 | +13.85% | 45.65 / 45.70 |
| 17 | 0.14592 | 0.14607 | 0.14600 | 基准 | 45.54 / 45.55 |
| 33 | 0.14969 | 0.14650 | 0.14810 | +1.44% | 45.56 / 45.54 |

输入两路平均恒模代价为 1.22496，EVM X/Y 为 53.40% / 52.98%。原始数值见 [comparison.csv](comparison.csv) 与 [input_metrics.csv](input_metrics.csv)。

1. **缩短到 5 抽头确实明显退化，9 抽头也有退化。** 两路指标方向一致，且[全程曲线](convergence.png)显示短抽头进入了较高的误差平台，不只是最后一个更新点偶然偏高。
2. **17 与 33 抽头接近。** 当前固定参数下，17 是已测四组中平均恒模代价最低的一组，且系数数量更少，可暂作为折中候选；33 仍保留为教师参考基准。
3. **结果支持抽头长度需要折中。** 过短时可用于补偿的历史范围不足，是此次退化的合理解释，但未知真实信道，不能仅由此反推出信道长度。过长在有限数据和固定步长下也未必更好。
4. **尚未证明最小够用长度或全局最优长度。** 没有测试 11、13、15 等中间长度，也未扫描步长或更换数据。这里的百分比是本次数据的实测差异，不是跨数据集的统计显著性结论。
5. **不报告更短抽头一定收敛更快。** 沿用原速度判据：后向 50 组平均代价，两路低于 0.1 并连续保持 50 组。本轮均未达到，threshold_samples 为 NaN；曲线有明显下降并进入波动平台，但该阈值不能给出速度排名。

本轮单次用时约 10.94～11.45 秒，四组没有随抽头数呈清晰趋势。计时包含均衡函数内初始化、滤波、更新和统计，不含加载与绘图；不是严格性能基准。虽然短抽头减少梯度运算和系数存储，四组 FFT 长度相同，不能由本次计时宣称明显加速。

## 保留的初轮结果

初轮比较 17/33/65 抽头，两路平均恒模代价分别为 0.14600、0.14810、0.17859；65 比 33 高约 20.6%。这次没有删除不符合“更多抽头更好”预期的数据，也没有再增大抽头。

初轮最终汇总和验证记录保存在 [comparison_initial.csv](comparison_initial.csv)、[validation_initial.csv](validation_initial.csv)；65 抽头的 `cma_65.mat`、`convergence_65.csv` 保留。17/33 在本轮独立重跑后指标与初轮一致；各轮单次运行用时可能不同。

## 星座与相位的解释边界

[原始星座图](constellations_raw.png)仍是圆环，而非四簇点。[现有评价对齐图](constellations_aligned.png)只做功率归一化与一个常相位调整，没有频偏或时变相位补偿，不能宣称已经完成可靠解调。

[离线相位诊断](phase_evolution.png)仍显示接近 −0.01404 周/采样的持续旋转趋势；这仅支持频偏或时变相位的推断，不是已知真值，也没有用于修改输出。CMA 对整体旋转不敏感，因此改善恒模代价不等于恢复绝对相位。没有采样率，不换算成 Hz；没有发送参考，不报告 BER。

两路最大归一化互相关在 ±64 点延迟内，5 抽头约为 0.0712，其他三组约为 0.0131～0.0137；这是额外诊断，不能单独证明分离质量。更新范数随抽头维数变化，不能直接用其大小排名收敛速度。边缘能量指标每侧最多取 4 点，短滤波器两侧不重叠，其覆盖比例不同，不作为跨长度选型依据。
