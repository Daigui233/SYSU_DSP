# CMA 均衡模块

## For Human

复用 basic 的复数 FFT/IFFT，实现双路 CMA 的频域分块滤波；梯度与更新规则保持教师参考一致。已完成 33 抽头验证，当前对比 5/9/17/33 抽头，不加入相位恢复。

在仓库根目录的 MATLAB 命令窗口运行：

```matlab
addpath('cma/src');
run_cma;
```

入口会执行测试、四组实验并生成 `results/` 中的数据与图表。输入为教师提供的 `TD_TRdata.mat`，每路 639616 个复数样本；固定每块 32 点、每 4 块更新一次、步长 `2^-8`、目标模平方 2，各组均更新 4997 次。

抽头选择流程：先以参考的 33 抽头验证正确性，再保持输入、步长及更新次数一致，按 33→17→9→5 逐步缩短；根据末尾同一区间的恒模代价判断退化，选择规模与误差的折中。实际运行按 5/9/17/33 展示，各组独立初始化。

[实验分析](results/analysis.md)：17 与 33 接近，9 与 5 抽头的平均恒模代价比 17 分别高 13.9% 与 43.9%，暂将 17 作为本数据下的折中候选，33 保留为参考；未搜索全部长度，不宣称全局最优。星座仍呈圆环，EVM 为判决辅助估计。

## For Agent

- `src/` 放代码，`tests/` 放测试，`results/` 只保留最终数据。保持操作级注释，新增保护性校验先讨论，不改教师原始资料。
- `cma_config` 管参数；`cma_equalize` 管分块与更新；`cma_filter_block` 管频域滤波；`cma_update` 累积梯度；`qpsk_metrics/analyze_cma` 管评价与图表。
- 两路输入按列存储；四路抽头列顺序为 `xx,xy,yx,yy`。复用 basic 初始化与变换，滤波不取共轭，每组四块复用抽头频谱。
- M 抽头保留 M−1 个历史点，FFT 长度满足 `N>=M+31`，IFFT 取第 `M:M+31` 点；跨块不清空历史。
- 更新严格保持参考：`e=2-abs(y)^2`，累积 `step*e*y*conj(input_window)` 后除以 4，下一组生效；仅实现参考的 `clk_dly=1`。区分最后使用与最后更新的抽头。
- 修改后运行 `run_cma`，核对参考输出、误差和抽头历史。EVM 仅做评价用功率归一化与常相位对齐，无发送符号，不报告 BER；相位诊断不反馈到算法。
- 抽头对照只改变 `tap_len` 及必要的 FFT 长度，不改步长、更新次数或评价区间；当前四组均为 64 点 FFT。保留不符合预期的结果，按恒模代价比较，不为得到更漂亮的星座加入相位优化。
